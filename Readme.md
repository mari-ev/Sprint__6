# Автотесты для «Яндекс.Самокат» (6‑й спринт)

UI‑автотесты для учебного сервиса «Яндекс.Самокат».

## Что сделано

Выполнены все требования 6‑го спринта:
* написаны автотесты для двух сценариев:
  * проверка выпадающего списка в разделе **«Вопросы о важном»** (отдельный тест на каждый вопрос);
  * полный позитивный сценарий **заказа самоката** с двумя наборами данных (две точки входа: кнопки «Заказать» вверху и внизу страницы);
* реализован **Page Object Model**: локаторы и методы вынесены в отдельные классы для каждой страницы;
* использована **параметризация** тестов (для разных наборов данных при заказе самоката);
* сгенерирован и добавлен в репозиторий **Allure‑отчёт** с результатами тестов.
